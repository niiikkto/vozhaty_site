# Вожатка — портал для вожатых

**Удобный веб-сайт для хранения учебных материалов студентов-вожатых и участников студенческих педагогических отрядов (СПО).**

## О проекте

**Вожатка** — это информационный портал, где будущие и действующие вожатые могут:
- Находить и скачивать готовые учебные материалы (игры, сценарии, методички)
- Смотреть фото из лагерей
- Читать полезную информацию о вожатстве и СПО
- Быстро готовиться к работе в летнем лагере

Проект создан в рамках учебной практики по направлению **09.02.07 Информационные системы и программирование**.

## Основные возможности

- ✅ Удобный каталог учебных материалов с фильтрацией
- ✅ Галерея фотографий из детских лагерей

## Как запустить проект локально

### 1. Клонируй репозиторий

```bash
git clone https://github.com/niiikkto/vozhaty_site.git
cd vozhaty_site
```

### 2. Создай виртуальное окружение (рекомендуется)

```bash
python -m venv venv
venv\Scripts\activate    # Windows
# source venv/bin/activate  # MacOS / Linux
```

### 3. Установи зависимости

```bash
pip install django pillow
```

### 4. Выполни миграции

```bash
python manage.py makemigrations
python manage.py migrate
```

### 5. Создай суперпользователя

```bash
python manage.py createsuperuser
```

### 6. Запусти сервер

```bash
python manage.py runserver
```

Открой в браузере: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
